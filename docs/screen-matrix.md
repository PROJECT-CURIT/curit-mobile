# Figma/ZIP 기준 구현 매트릭스

2026-10-30 기준이다. `완료`는 운영 DB까지 연결된 기능, `통합`은 여러 Figma 화면을 한 흐름에 합친 기능, `부분`은 핵심 동작은 가능하지만 보조 편집 기능이 남은 상태다.

| 번호 | Figma 화면/기능 | 상태 | 실제 구현 |
| ---: | --- | --- | --- |
| 01 | 로그인 | 완료 | Supabase 이메일 인증·세션 유지 |
| 02 | 역할 선택 | 완료 | 크리에이터/매장 역할별 가입 |
| 03 | 크리에이터 가입 | 완료 | Auth 사용자·프로필 자동 생성 |
| 04 | 매장 가입 | 완료 | Auth 사용자 생성 후 5단계 온보딩 연결 |
| 05 | 크리에이터 홈 | 완료 | 서버 추천 매장·실제 정산 요약 |
| 06 | 크리에이터 마이 | 완료 | 프로젝트·설정 진입 |
| 07 | 크리에이터 프로필 | 통합 | 프로필·프로젝트 데이터로 추천 DNA 구성 |
| 08 | 프로필 편집 | 부분 | DB 구조는 완료, 전용 편집 화면은 후속 |
| 09 | 크리에이터 프로젝트 | 완료 | 프로젝트 조회·상품 이미지 업로드·추가 |
| 10 | 크리에이터 협업 | 완료 | 제안 확인·승인·조정·취소·완료 상태 전이 |
| 11 | 크리에이터 정산 | 완료 | 실제 주문 기반 정산 원장 조회 |
| 12 | 매장 디렉터리 | 완료 | DB 매장 추천·검색·적합도와 추천 이유 |
| 13 | 매장 홈 | 완료 | 서버 추천 작품·실제 주문/정산 요약 |
| 14 | 매장 마이 | 완료 | 매장 정보·설정 진입 |
| 15 | 매장 취향 | 완료 | 공간 DNA와 추천 조건 DB 저장 |
| 16 | 매장 프로필 | 통합 | 마이·온보딩 화면에 통합 |
| 17 | 매장 운영 | 완료 | 실제 협업 상태·QR·정산 진입 |
| 18 | 매장 QR 목록 | 완료 | 협업·상품별 발급 후보와 실제 QR 목록 |
| 19 | QR 상품 편집 | 부분 | 발급·재고·판매 상태 조회 완료, 개별 가격 편집은 제한 |
| 20 | QR 데이터 미리보기 | 완료 | 상품별 QR·구매 웹 연결 |
| 21 | 매장 수령 | 부분 | 결제 완료 주문 생성은 완료, 직원용 전달 완료 버튼은 후속 |
| 22 | 매장 판매 | 완료 | 실결제·재고 차감·정산 원장 |
| 23 | 크리에이터 DNA | 통합 | 프로필·프로젝트·상품 소재/지역으로 자동 구성 |
| 24 | 크리에이터 프로필 설정 | 부분 | 서버 데이터 지원, 별도 단계형 온보딩은 후속 |
| 25 | 프로젝트 기본정보 | 부분 | 기본 프로젝트 자동 생성, 제목·스토리 전용 편집은 후속 |
| 26 | 굿즈 폼 | 완료 | 이미지 영구 저장·가격·재고·유형 검증 |
| 27 | 작품 폼 | 통합 | 26의 상품 유형 선택에 통합 |
| 28 | 프로젝트 최종확인 | 통합 | 내 전시 프로젝트 화면에서 확인·수정 |
| 29 | 매장 기본정보 | 완료 | 필수값 검증·중간 저장 |
| 30 | 매장 취향 | 완료 | 분위기·목적·예산 저장 |
| 31 | 매장 사진 | 완료 | Supabase Storage 영구 저장 |
| 32 | 전시 구역 | 완료 | 구역·크기 저장 |
| 33 | 매장 최종확인 | 완료 | 5단계 완료 전 로그인 차단 |
| 34 | 협업 요청 | 완료 | 추천 카드 → 실제 제안 RPC |
| 35 | 크리에이터 제안 | 완료 | 승인/조건 수정 요청/취소 |
| 36 | 매장 협업 상세 | 완료 | 매장 최종 확정·협업 채팅·배분/기간 표시 |
| 추가 | AI 큐레이터 | 완료 | 대화 저장·설명 가능한 추천·후보 3개·제안 연결 |

핵심 시연 경로는 `공간/작품 데이터 등록 → AI 대화 → 추천 근거와 후보 → 협업 제안 → 크리에이터 승인 → 매장 최종 확정 → 상품별 QR 발급 → 토스 테스트 결제 → 재고 차감 → 정산 원장`으로 서버까지 연결된다.

프로토타입의 커뮤니티·팔로우·좋아요 같은 소셜 기능은 핵심 거래 검증과 무관하고 운영 비용만 늘리므로 이번 본선 구현 범위에서 제외했다. 이는 구현 누락을 완료로 표시한 것이 아니라, 사업 핵심 흐름을 우선한 의도적인 범위 결정이다.
