핵심 시연 경로는 `공간/작품 데이터 등록 → AI 대화 → 추천 근거와 후보 → 협업 제안 → 크리에이터 승인 → 매장 최종 확정 → 상품별 QR 발급 → 토스 테스트 결제 → 재고 차감 → 정산 원장`으로 서버까지 연결된다.

핵심 거래 흐름뿐 아니라 Figma Make에 있던 프로필·커뮤니티·팔로우·좋아요·댓글·알림·프로젝트 편집·매장 운영 보조 기능도 구현했다. Android 앱에는 Firebase 앱 설정과 푸시 토큰 등록 코드가 포함돼 있지만 EAS 프로젝트의 FCM v1 서비스 계정 자격 증명은 아직 등록되지 않아 원격 수신은 검증하지 못했다. 통신사 본인확인과 실제 판매대금 지급처럼 외부 사업자 계약이 필요한 기능은 화면 구현과 구분하며, 현재는 인앱 알림·연락처 확인·주문 확인·정산 원장 생성 범위까지 제공한다. QR 조회는 익명 브라우저별 하루 1회만 집계해 매장 관리와 상품 관리 화면에 연결한다.
