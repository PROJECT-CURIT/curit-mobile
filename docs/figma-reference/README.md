# 최신 웹 참고 화면

이 폴더에는 정리한 웹 앱을 실제 Chromium에서 실행해 캡처한 **36개 화면/상태**가 있습니다.
기준 viewport는 **390 × 844**, device scale은 1입니다.

- `01`–`04`: 로그인·역할 선택·두 역할의 가입 첫 단계
- `05`–`12`: 크리에이터 홈·마이·프로필·프로젝트·협업·정산·매장 탐색
- `13`–`22`: 매장 홈·마이·공간 설정·프로필·관리·QR·수령·판매
- `23`–`28`: DNA·프로필 설정·프로젝트 기본 정보·굿즈/작품 입력·최종 확인
- `29`–`33`: 매장 기본 정보·취향·사진·구역·최종 확인
- `34`–`36`: 협업 요청·작가 공급 답변·매장 확정 상세

각 PNG 옆의 `.layout.json`은 해당 상태에서 viewport에 보이는 컨트롤의 위치·크기,
폰트·줄 높이·색상·padding·border radius를 기록합니다.
입력 화면 캡처는 측정 전에 스크롤을 위로 되돌렸습니다.
역할별 화면 캡처는 저장된 테스트 상태의 기본 화면 또는 선택한 탭 상태입니다.
이 자료는 모든 가능한 모달/스크롤/빈 상태를 망라하지 않으므로 나머지는 소스를 확인합니다.

캡처의 이름·소개·상품·주문은 격리한 테스트 계정 데이터입니다.
실제 계정 데이터나 초기 기본 운영 데이터로 복사하지 마세요.
비밀번호/브라우저 저장 파일은 이 폴더에 넣지 않았습니다.

렌더링 참고를 위해 브라우저에서 공개 CDN의 Pretendard와 외부 사진 로딩을 사용했습니다.
네이티브에서는 동일 폰트 파일을 별도로 준비해야 합니다.
retina 기기의 스크린샷은 비교 전에 논리 좌표 390 × 844에 맞게 정규화하되 앱 자체의 글자·간격을 비율 변경하지 마세요.

웹의 폰 모양 외곽 프레임과 가짜 시스템 표시 영역을 네이티브 앱 콘텐츠에 중복 적용하지 마세요.
자세한 내용은 `../PORTING_SPEC.md`를 따릅니다.
