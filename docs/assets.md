# 디자인 자산 출처

- 앱 본문 폰트: Pretendard 1.3.9, SIL Open Font License 1.1. 라이선스 원문은 `assets/fonts/PRETENDARD-LICENSE.txt`에 포함했다.
- 이미지: Figma Make 원본에서 사용한 Unsplash 이미지 URL을 같은 크롭 기준으로 로컬에 번들했다. 네트워크가 끊겨도 피그마 기준 화면을 재현하기 위한 용도다.
- 앱 아이콘: CURI:T 브랜드 색상 `#4A6338`과 워드마크를 사용해 저장소 안에서 새로 제작했다. 원본 SVG는 `assets/brand-icon.svg`다.

운영 출시 전에는 Unsplash 이미지 대신 실제 참여 작가와 매장의 사용 허가를 받은 이미지로 교체해야 한다. 현재 이미지는 프로토타입 시연용이다.
